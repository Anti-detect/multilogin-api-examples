# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| latest `main` | Yes |

## Reporting a vulnerability

This repo contains **example code only** — not Multilogin product itself.

- **Multilogin product issues:** contact [Multilogin Support](https://multilogin.com/help/)
- **Issues in this repo's code:** open a [GitHub Security Advisory](https://github.com/Anti-detect/multilogin-api-examples/security/advisories/new) or a private issue

**Never** include automation tokens, profile cookies, or passwords in reports.

## Scope

In scope for this repository:

- Example scripts leaking secrets in docs
- Insecure defaults in sample code

Out of scope:

- Multilogin application vulnerabilities (report to vendor)
- Platform ToS violations using antidetect browsers
