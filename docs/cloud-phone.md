# Multilogin Cloud Phone

Cloud Phone lets you run **mobile app workflows** from the cloud without physical devices — useful for TikTok, Instagram, banking apps, and other mobile-only platforms.

## What It Does

- Emulates Android devices in the cloud
- Isolated mobile fingerprints per instance
- Integrates with Multilogin workspace for team management
- Reduces hardware cost vs. a device farm

## When to Use Cloud Phone vs Browser Profiles

| Scenario | Recommended |
|----------|-------------|
| Web-based platforms (Amazon Seller, Facebook Ads) | Browser profile (Mimic / Stealthfox) |
| Mobile-only apps (certain social, fintech) | Cloud Phone |
| Mixed web + app on same account | Separate profiles; avoid cross-linking |

## Best Practices

- Match device locale and IP region
- One instance per account — same isolation rules as browser profiles
- Avoid rapid account switching on a single instance
- Keep app versions consistent with the emulated OS
