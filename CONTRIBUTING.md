# Contributing

Thanks for improving **[Anti-detect/multilogin-api-examples](https://github.com/Anti-detect/multilogin-api-examples)**.

## What we want

- Corrected API paths or response field names after Multilogin updates
- Additional minimal examples (Node.js curl scripts, Selenium snippets)
- Clearer troubleshooting entries
- Typos and broken links

## What we don't want

- Cracks, license bypasses, or stolen tokens
- Credentials, real profile UUIDs, or automation tokens in PRs
- Spam links unrelated to Multilogin documentation
- Impersonation of official Multilogin support

## Pull request checklist

1. Test against a running Multilogin X agent locally
2. Use environment variables for secrets
3. Link to [official Postman API](https://documenter.getpostman.com/view/28533318/2s946h9Cv9) when documenting endpoints
4. Keep examples short and copy-paste friendly

## Issues

Include: OS, Multilogin app version (if known), error message, steps — **never** paste your automation token.
